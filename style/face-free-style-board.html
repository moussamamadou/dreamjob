STYLE FILE · NO FACES REQUIRED

Six styles that never draw a face

One sample frame per style. None of them depends on keeping a face on-model, so none of them can drift. Recommendation: Isotype Ledger animated in Remotion for the explaining, and Cut Paper Noir animated in MiniMax for titles, thumbnails and the heavy moments. Keep every word out of the art and add it in Remotion after MiniMax.

Isotype Ledger Recommended

Everyone is the same pictogram. The outlaw gets one hat and the red. Numbers are rows of figures.

Built with
Code only
Cost
0 credits
Best for
Money, promotions, org charts, book interiors
In MiniMax
Don't send it. Animate it in Remotion, where figures count in exactly; MiniMax would smear the crisp shapes.

Cut Paper Noir Pair with Isotype

Torn and cut paper, black does the work, the outlaw is a silhouette with dot eyes and a hatband.

Built with
Image model
Cost
~10–20 credits / episode
Best for
Titles, thumbnails, covers, arrests, the exit interview
In MiniMax
Best fit. Big flat shapes with little detail survive well. Use slow pushes, drifting smoke and falling paper.

Evidence Table Second choice

Seen from above. His objects and his sleeve tell the story; no head ever enters the frame.

Built with
Image model for objects, code for papers
Cost
~7–10 credits per outlaw, then reused
Best for
Deals, money, documents, Tricks of the trade Shorts
In MiniMax
Good for objects (smoke, sliding coins, a ringing phone). Hands may warp, so keep hand moves short or do them in Remotion.

Blueprint

Floor plans, routes and cutaways. People are tiny labelled scale figures; the plan is the hero.

Built with
Mostly code
Cost
1–3 credits / episode
Best for
Heists, escapes, tunnels, ships
In MiniMax
Don't send it. Draw-on lines and routes are exact in Remotion; MiniMax would wobble the lines.

Game Board

The career is a board game. The outlaw is a red pawn with a fedora; events are cards.

Built with
Code board + 1 token per character
Cost
~1 credit per character
Best for
Journeys, rivalries, territory
In MiniMax
Fair. Use slow board pans and one token moving. Exact square-by-square moves are hard to control.

Silhouette Theatre WHO AM I? style

Black puppets in profile against coloured light, in the Lotte Reiniger tradition.

Built with
Image model + Remotion light
Cost
~5–15 credits / episode
Best for
Mystery, biography, emotion
In MiniMax
Very good. Solid black shapes give it nothing to drift; the coloured light can pulse and flicker.
Isotype and Blueprint frames were drawn in code (0 credits). Evidence Table, Game Board and Silhouette Theatre are quick Recraft tests (1 credit each). All figures and plans in the samples are illustrative, not sourced.
